# Zero-Shot Text Classification using ReGen Progressive Dense Retrieval

## Project Overview

This project explores **Zero-Shot Text Classification** using a
retrieval-based approach inspired by the research paper:

**"Zero-Shot Text Classification using ReGen Progressive Dense
Retrieval"**

The repository contains my implementation, experimentation, and
modifications based on the original research concept.

The main focus is understanding how modern NLP techniques can classify
text into categories without requiring large amounts of labeled training
data.

------------------------------------------------------------------------

## Objectives

-   Understand zero-shot learning techniques in NLP
-   Explore transformer-based text representation methods
-   Implement a retrieval-based classification workflow
-   Experiment with dense retrieval and semantic similarity approaches
